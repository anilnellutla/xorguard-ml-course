# Solutions

Worked answers to each lesson's `EXERCISES`. **Try the exercise first** — the
struggle is where the learning happens. These are here to check yourself against,
or to unstick you, not to skip ahead with.

Each `lesson_NN_solution.py` is runnable on its own:

```bash
python solutions/lesson_04_solution.py
```

They import from the lessons, so run them from the repo root (as above) or with
the `lessons/` directory importable.
